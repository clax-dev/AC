1 · QUÉ ES UNA LAMBDA

Una nota con instrucciones

FormaEjemplo
Sin parámetros() -> "Hola"
Un parámetroinc -> inc.id()
Varios(a, b) -> a + b
Con bloquex -> { ...; return y; }
Reglas• Siempre se guarda en una interfaz funcional (un solo método abstracto).
• Solo usa variables de fuera efectivamente finales.
• El parámetro es un elemento: nombre en singular (linea).
«Una lambda es una función sin nombre que se guarda o se pasa, y no se ejecuta hasta que alguien la llama.»

2 · INTERFACES FUNCIONALES

Cinco tipos de encargo

🚪Predicate<T> · testEl portero: ¿pasa o no? T → boolean
inc -> !inc.resuelta()
⚙️Function<T,R> · applyLa máquina: entra una cosa, sale otra. T → R
inc -> "#" + inc.id()
👷Consumer<T> · acceptEl operario: hace algo, no devuelve. T → nada
inc -> System.out.println(inc)
🏭Supplier<T> · getLa fábrica: no recibe, da algo. nada → T
() -> Math.random()
⚖️Comparator<T> · compareEl juez: ¿quién va antes? T, T → int
🤔¿Cuál elijo?¿boolean? → Predicate
¿no devuelve? → Consumer
¿no recibe? → Supplier
¿recibe y devuelve? → Function

record · enum · switch · Factory

record Incidencia(int id, String usuario, Prioridad prioridad, boolean resuelta) { }
inc.id();   // getter SIN get · inmutable

enum Prioridad {
    ALTA(3), MEDIA(2), BAJA(1);
    private final int peso;
    Prioridad(int peso) { this.peso = peso; }
}

String t = switch (p) {      // sin break, devuelve valor
    case ALTA -> "Urgente";
    case MEDIA, BAJA -> "Normal";
};
