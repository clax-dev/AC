ObjectMapper: el traductor

Lo que necesita la clase molde• Constructor vacío (crea y luego rellena)
• Setters para leer · getters para escribir
• Mismo nombre que la clave → si no, @JsonProperty("clave")
• Un record también vale
Claves que la clase no tienePor defecto: UnrecognizedPropertyException.
mapper.configure(DeserializationFeature.

o @JsonIgnoreProperties(ignoreUnknown = true).
Imprescindible con APIs grandes como PokeAPI.

4 · MOLDE O ÁRBOL

Dos formas de leer un JSON

🧱 Con molde: readValueConoces la forma y quieres objetos con getters.
Pelicula p = mapper.readValue(json, Pelicula.class);
p.getTitulo();

// un JSON que es una lista [ {...}, {...} ]
List<Pelicula> l = mapper.readValue(json,
        new TypeReference<List<Pelicula>>() {});
🌳 Como árbol: readTreeSolo quieres un par de datos de un JSON enorme, sin crear clases.
JsonNode raiz = mapper.readTree(json);
raiz.get("titulo").asText();
raiz.get("director").get("nombre").asText();
for (JsonNode g : raiz.get("generos")) {
    System.out.println(g.asText());
}
Método de JsonNodeQué hace
get("x")el hijo; null si no existe (el siguiente método da NullPointerException)
path("x")igual, pero devuelve un nodo vacío en vez de null
get(i) · size() · isArray()trabajar con listas
asText() · asInt() · asDouble()el valor convertido

El cartero, la carta y la respuesta

📮HttpClientEl cartero. Se crea una vez (static final).
send() espera · sendAsync() no (CompletableFuture, como el Future de PSP)
✉️HttpRequestLa carta: newBuilder().uri(...)
.header(...).GET().build()
📬HttpResponse<String>La respuesta: statusCode() y body() (el JSON en texto)
https://pokeapi.co/api/v2/pokemon/charmander
└esquema┘└─ host ─┘└───── endpoint ─────────┘

HttpResponse<String> r = CLIENTE.send(peticion,
        HttpResponse.BodyHandlers.ofString());
if (r.statusCode() < 200 || r.statusCode() >= 300)
    throw new IOException("HTTP " + r.statusCode());
String json = r.body();   // → Jackson
