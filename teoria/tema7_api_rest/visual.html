4 · SPRING BOOT

El food truck frente a la normativa

🚚Spring Boot: el food truck La cocina viaja con el negocio: el servidor va dentro de tu aplicación.

• Framework que decide por ti: «todo incluido»
• Genera un .jar que arranca solo
• Comienzo más suave
• Startups, microservicios, app de reparto
📜Jakarta EE: la normativa Dice cómo debe ser una cocina, pero tú eliges el local (WildFly, Payara, TomEE).

• Estándar: «define las reglas»
• Genera un .war o .ear para un servidor externo
• Más conceptual al principio
• Banca, seguros, gobierno, sistemas de décadas
⚙️ AutoconfiguraciónEvita el código repetido. Una API en minutos, no en un día.
🍽️ Servidor embebidoTomcat va dentro. No hay que instalar nada aparte.
🧰 De fábricaActuator (salud), Spring Security y Spring Data.

5 · DTO Y MAPPER

Nunca sirvas el ingrediente crudo

EntidadEs igual a la tabla: la lleva @Entity y va unida a la base de datos.
DTOClase sencilla, sin anotaciones de base de datos. Solo lo que entra o sale.
MapperConvierte en los dos sentidos: DTO → entidad y entidad → DTO.
«El Controller recibe y devuelve DTOs, nunca entidades.» Así controlas qué campos salen en el JSON.

7-8 · CONTROLLER Y REPOSITORY

El verbo dice qué, la URL dice sobre qué

VerboAnotaciónAcciónSQL
GET@GetMappingConsultarSELECT
POST@PostMappingCrearINSERT
PUT / PATCH@PutMappingActualizarUPDATE
DELETE@DeleteMappingBorrarDELETE
@ResponseStatus cambia el código de éxito: por ejemplo, 201 Created en vez del 200 OK normal.
@RestController             // devuelve datos
@RequestMapping("/api/clientes") // ruta base
public class ClienteController {

  @GetMapping               // GET /api/clientes
  ... listarClientes() { ... }

  @GetMapping("/{id}")       // GET /api/clientes/7
  ... buscar(@PathVariable Long id) { ... }
}
