6-7 · OPCIONES DE APERTURA Y EXCEPCIONES

¿Y si el fichero ya existe?

(ninguna)No existe → lo crea.
Existe → lo vacía y escribe de cero.
Datos que se regeneran
CREATE_NEWNo existe → lo crea.
Existe → se niega: FileAlreadyExistsException.
Configuración (Laboratorio B1)
CREATE + APPENDNo existe → lo crea.
Existe → añade al final.
Logs (Laboratorio B2, BioDAM)
¿Por qué no «if (!exists) write»?Entre comprobar y escribir hay un hueco: otro puede crearlo y lo machacas. CREATE_NEW lo hace en un paso (atómico). Es el «comprobar y luego actuar» de PSP.

APPEND solo falla si no existe → por eso va con CREATE.
Excepción (hija de IOException, checked)Cuándo
NoSuchFileExceptionno existe
FileAlreadyExistsExceptionya existe
DirectoryNotEmptyExceptionborrar carpeta llena
AccessDeniedExceptionsin permiso
EOFExceptionfin de un binario
NotSerializableExceptionclase sin Serializable
try { Files.write(config, propiedades, StandardOpenOption.CREATE_NEW); }
catch (FileAlreadyExistsException e) { System.out.println("Ya existía: no lo toco"); }   // la CONCRETA, no IOException
Files.writeString(log, linea + System.lineSeparator(), StandardOpenOption.CREATE, StandardOpenOption.APPEND);

8 · SEGURIDAD

Path Traversal: «..» sube una carpeta

// 1. absoluta y LUEGO normalize, en las DOS
Path base = Paths.get("datos").toAbsolutePath().normalize();
Path cand = Paths.get(ruta).toAbsolutePath().normalize();
// 2. Path.startsWith: carpeta a carpeta
if (!cand.startsWith(base)) {
    throw new SecurityException("Fuera de datos/: " + ruta);
}
Ruta del usuarioResultado
datos/diagnosticos.csvdentro
datos/../../etc/passwdse sale
datos/essd/pppdentro (aunque no exista)
datos2/secreto.txtPath: fuera ✓
String.startsWith: ¡se cuela!
«Normaliza las dos rutas y compara carpeta a carpeta (Path.startsWith), nunca letra a letra (String.startsWith).»

9 · GUARDAR OBJETOS

Cuatro formatos, cuatro usos

📄 CSV (F03)codigo;nombre;precio + una línea por objeto.
Guardar: String.join(";", …) · Cargar: skip(1) + split(";") + parseInt/parseDouble.
✅ lo abre Excel y cualquier lenguaje · ⚠ decimales con punto (Locale.ROOT)
🔢 DataOutput/InputStream (F04)writeUTF · writeDouble · writeInt
Mismo orden y mismos tipos al leer, o basura sin error.
Fin del fichero → EOFException (no null).
📦 Serialización (F05)ObjectOutputStream.writeObject(lista) · (Cast) readObject()
implements Serializable (marca) · serialVersionUID (versión → InvalidClassException) · transient = no se guarda (null/0/false).
⚠ solo lo entiende Java
🎯 Acceso aleatorio (F06)RandomAccessFile(f, "rw") + seek(n × TAM)
Registros de tamaño fijo (textos rellenos de espacios).
✅ leer o cambiar un registro sin tocar el resto.
Necesito…Formato
Que lo lea una persona, Excel u otro programaCSV
Guardar y recuperar objetos Java rápidoSerialización
Muchos registros e ir directo a uno, o modificarloAcceso aleatorio
